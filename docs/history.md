# История коммитов

История изменений проекта Geometric Library. Последний коммит с созданием этих файлов в список не включён.

## `8ba9aeb` — L-03: Circle and square added

Добавлены файлы `circle.py` и `square.py` с функциями для вычисления площади и периметра круга и квадрата.

## `d078c8d` — L-03: Docs added

Добавлена первоначальная документация с математическими формулами для геометрических фигур.

## `7d6855d` — Добавлен файл rectangle.py

Добавлен файл `rectangle.py` с функциями площади и периметра прямоугольника.

## `372c144` — Исправлен периметр прямоугольника и добавлен triangle.py

Исправлена формула периметра прямоугольника и добавлен файл `triangle.py` с функциями площади и периметра треугольника.

## `8f4c141` — Добавлена документация функций

В функции всех четырёх модулей добавлены docstring с описаниями и примерами вызова.

## `4413542` — Обновлена документация проекта

В `docs/README.md` добавлены описание библиотеки, сведения о функциях, примеры и история изменений.
