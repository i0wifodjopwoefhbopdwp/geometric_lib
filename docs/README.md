# Geometric Lib

Geometric Lib — библиотека на Python для вычисления площади и периметра геометрических фигур: круга, квадрата, прямоугольника и треугольника.

## Круг

### Площадь круга

Функция `area(r)` из файла `circle.py` вычисляет площадь круга радиуса `r`.

Пример вызова:

    area(2)

### Длина окружности

Функция `perimeter(r)` вычисляет длину окружности радиуса `r`.

Пример вызова:

    perimeter(2)

## Квадрат

### Площадь квадрата

Функция `area(a)` из файла `square.py` вычисляет площадь квадрата со стороной `a`.

Пример вызова:

    area(4)

### Периметр квадрата

Функция `perimeter(a)` вычисляет периметр квадрата.

Пример вызова:

    perimeter(4)

## Прямоугольник

### Площадь прямоугольника

Функция `area(a, b)` из файла `rectangle.py` вычисляет площадь прямоугольника.

Пример вызова:

    area(4, 5)

### Периметр прямоугольника

Функция `perimeter(a, b)` вычисляет периметр прямоугольника.

Пример вызова:

    perimeter(4, 5)

## Треугольник

### Площадь треугольника

Функция `area(a, h)` из файла `triangle.py` вычисляет площадь треугольника по основанию и высоте.

Пример вызова:

    area(4, 5)

### Периметр треугольника

Функция `perimeter(a, b, c)` вычисляет периметр треугольника.

Пример вызова:

    perimeter(3, 4, 5)
