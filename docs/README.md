# Geometric Library

Небольшая библиотека на Python для вычисления площади и периметра геометрических фигур. Проект состоит из четырёх модулей:

- `circle.py` — вычисления для круга.
- `square.py` — вычисления для квадрата.
- `rectangle.py` — вычисления для прямоугольника.
- `triangle.py` — вычисления для треугольника.

## Математические формулы

### Площадь

- Круг: `S = πR²`
- Квадрат: `S = a²`
- Прямоугольник: `S = ab`
- Треугольник: `S = ah / 2`

### Периметр

- Круг: `P = 2πR`
- Квадрат: `P = 4a`
- Прямоугольник: `P = 2(a + b)`
- Треугольник: `P = a + b + c`
